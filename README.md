## 🌟 核心特性与业务架构

### 1. 📊 干部全息个人立体画像
- **基本档案与身份认定**：整合员工工号、身份证号、校编/院编/人事代理编制形态、党政管理岗/业务管理岗分类。
- **两级学历与初始学历核准**：精准呈现第一学历（初始学历）与最高学历、学位层次、毕业院校及专业，彻底规避学历信息混淆。
- **政治面貌精准识别**：中共党员、民主党派（九三学社、民盟等）与党外群众规范分类，非党员留空绝不误判。
- **任职任级年限动态核算**：自动计算任现职时长、任现级时长、同一岗位任职时长，红黄预警标识清晰直观。

### 2. ⚡ 队伍结构大数据看板与决策大盘
- **多维结构分析**：一键掌握干部队伍总规模、平均年龄、40岁以下青年骨干占比、硕博高学历比例、高级职称密度、党员与女性干部比例。
- **智能预警机制**：
  - 🔄 **轮岗交流预警**：同一岗位任职满 5 年自动提醒轮岗，满两届（8年）达任职最高任期红线预警。
  - 📈 **选拔提拔初筛**：任副科满 2 年、任正科满 3 年提拔资格合规性自动研判。
  - ⏳ **临近退休关怀**：根据性别、职称、职级及干部身份自动推算退休年月并提前预警。

### 3. 📜 公文穿透检索与任职时间轴自动闭合
- **公文智能索引**：自动深度穿透扫描 `任免文件库/` 下所有红头任免文件（Word 与 PDF 格式），提取任职、免职及试用期条款。
- **履历自动缝合**：将孤立的公文记录与干部个人档案双向绑定，自动生成个人任职历史演变时间轴。
- **试用期转正自动点亮**：干部一年试用期满并考核合格后，系统自动点亮“试用期满转正”金色合规徽章。

### 4. 👥 处级干部独立管理专区
- 针对高校、医院处级领导干部特点，设立独立管理通道。
- 支持细分为 **【单位领导班子】**、**【直属/分支机构领导】**、**【专业内设机构领导】**。
- 支持分管业务、分管部门的细颗粒度维护，与科级大盘既相互独立又统一归档。

### 5. 🛡️ 纪律红线与任职回避合规监测
- **纪检处分闭环**：穿透扫描党纪政务处分及诫勉处理决定，自动核算影响期。受处分干部在提拔研判中实行**红线一票否决**。
- **同院亲属任职回避监测**：智能穿透家庭成员信息，排查具有夫妻、直系血亲、三代以内旁系血亲关系干部的职务交叉，一键生成合规排查专项台账。

### 6. 🖨️ 全格式法定报表一键导出
- **标准 Word 干部任免审批表**：严格契合国家标准版式，照片、履历、家庭成员、奖惩自动排版排版对齐。
- **PDF 干部全息画像汇报单**：高清矢量呈现，包含任职时间轴与三维画像，供党委会/常委会即席审议。
- **Excel 常委会全景研判分析报告**：全院总体、党政序列、业务序列三套横向对比数据报表一键导出。

## 📥 初始数据准备与批量导入指南

系统开放提供了完全脱敏的标准空白表样（位于 `导入数据模板样例/` 文件夹），供任何新单位直接参考填报：

| 模板文件名 | 适用业务场景 | 核心填报内容 |
| :--- | :--- | :--- |
| **`中层干部名册(标准模板).xlsx`** | 科级及中层干部核心底账 | 姓名、职务、级别、学历、任现职时间、现级时间等 21 列标准字段 |
| **`处级干部名册(标准模板).xlsx`** | 处级干部专门名册 | 姓名、职务、级别、归口类别（班子/直属/内设）、分管业务、政治面貌 |
| **`科级干部联系方式统计表(标准模板).xlsx`**| 通讯录批量更新 | 姓名、职务、移动电话、办公固话、办公地点 |
| **`人员花名册(标准模板).xlsx`** | 全院职工大底账 | 身份证号、初始学历/最高学历、毕业院校与专业（用于双表深度核准） |
| **`干部任免审批表(标准模板).docx`** | 法定审批表空白版式 | 预设标准表头与排版网格，供系统填充回填 |

### 批量导入步骤：
1. 打开 `导入数据模板样例/` 文件夹，将贵单位干部数据填入对应表格；
2. 启动系统：
   - 导入科级干部：点击顶部工具栏 **【📥 增量导入名册】**；
   - 导入处级干部：进入左侧【处级干部管理专区】，点击 **【📥 批量导入处级名册(Excel)】**；
3. 系统自动完成多表校验比对，确认后点击“确定”即可瞬间入库生效！

## 🔒 数据安全与离线保密承诺

干部人事信息属于高度敏感数据，本系统在架构设计上坚守以下三项底线原则：
1. **100% 本地单机离线运行**：软件不依赖任何外部网络接口，运行期间零联网、零外传，杜绝信息泄露。
2. **本地高并发嵌入式数据库**：所有数据存放于单文件 SQLite 数据库（`干部任免数据索引.db`），自主可控，备份与迁移仅需复制该文件即可。
3. **开源代码零泄密审计**：本开源仓库已严格通过文件隐私过滤机制，绝不包含任何真实单位人员信息、真实红头公文及内部审批表，所附模板均为脱敏表样。

## 🛠️ 打包独立 EXE 指南 (Windows)

在 Windows 源码环境下，执行以下单行命令即可直接打包为无需 Python 环境的单文件 exe：

```cmd
pyinstaller --noconfirm --clean --onefile --windowed --name "干部任免检索系统" --add-data "XXX干部任免审批表(模板).docx;." --hidden-import "cadre_core" --hidden-import "openpyxl" --hidden-import "docx" --hidden-import "pypdf" --hidden-import "PySide6.QtPrintSupport" 干部任免检索系统.py
```
打包成功后，在 `dist/` 目录下即可获得 `干部任免检索系统.exe`。
