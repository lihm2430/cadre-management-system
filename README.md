# 科级干部全周期管理与综合研判系统

基于 **PySide6** 与 **SQLite** 构建的高性能现代化科级干部全周期人事管理、公文归档、智能研判与决策支持桌面系统。

---

## 🌟 核心特性

- **三维全景个人画像卡**：深度整合基本身份、任职任级年限、第一学历与最高学历、纪律监督及退休预警研判。
- **公文时间轴与自动闭合引擎**：穿透红头任命通知与考核公文，支持新提拔试用期条款提取与考核合格转正徽章自动点亮。
- **双表智能比对与履职深度缝合**：支持审批表与人员花名册交叉纠偏、历史断层自愈及增量保护。
- **干部档案智能核查与任职回避监测**：同院亲属任职回避智能预警与排查清单导出。
- **决策大盘与高管研判看板**：多维度干部队伍梯队分析、科级处级分类管理。
- **全格式报表一键导出**：一键生成标准 Word 任免审批表、PDF 干部全息汇报单及 Excel 档案表。

## 🚀 快速启动

### 依赖环境
- Python 3.9+
- 推荐使用 Windows 10/11 或 macOS

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行系统
```bash
# Windows
双击运行 启动系统.bat
# 或执行命令
python 干部任免检索系统.py

# macOS / Linux
python3 干部任免检索系统.py
```

### 3. 生成独立 EXE (Windows)
```bash
双击运行 打包为独立EXE(可选).bat
```
打包成功后，可在 `dist/` 目录下获取 `干部全周期管理系统.exe`。

## 📥 初始数据准备与批量导入指南

开源版本已在 `导入数据模板样例/` 目录下提供了完全脱敏的标准空白表样，供新单位或新用户直接参考与填报：

1. **`中层干部名册(标准模板).xlsx`**：干部核心现任底账（含科室、现任职务、现职时间、现级时间、专技职务、年龄等 21 列标准字段）。
2. **`人员花名册(标准模板).xlsx`**：单位全员干部人事全景底账（含身份证号、第一学历/最高学历、毕业院校与专业、入职时间等 44 列精细画像字段）。
3. **`科级干部联系方式统计表(标准模板).xlsx`**：干部移动电话等通讯联系台账。
4. **`干部任免审批表(标准模板).docx`**：符合国家标准版式的空白审批表，用于系统一键回填与自动排版导出。

### 批量导入步骤：
1. 打开 `导入数据模板样例/` 文件夹，将各表填写并保存为以下名称，放置于系统**根目录**：
   - `中层干部名册（模版）.xlsx`
   - `人员花名册（模板）.xlsx`
   - `科级干部联系方式统计表.xlsx`
2. 启动系统后，点击顶部工具栏的 **【⚡ 一键全员底表校准与公文智能治理】** 按钮。
3. 系统将自动执行多表融合校验、跨表身份证/工号关联纠偏、履历断层智能缝合，并写入本地高敏隔离数据库 `干部任免数据索引.db`。

## 📁 目录结构说明

- `干部任免检索系统.py`：系统主入口、界面调度及全员治理引擎
- `cadre_core.py`：核心数据模型、全息卡片、时间轴组件及履历自愈闭合算法
- `导入数据模板样例/`：开放提供的标准脱敏导入 Excel/Word 模版（纯表头及虚拟张三李四示例）
- `generate_mock_data.py`：模拟测试数据生成工具
- `任免文件库/`：存放红头任免公文原件（Word/PDF，系统已配置隐私忽略）
- `干部任免审批表库/`：存放干部任免审批表原件（系统已配置隐私忽略）
- `纪律处分文件库/`：存放纪律处分发文及通报（系统已配置隐私忽略）
- `requirements.txt`：Python 运行依赖项清单
