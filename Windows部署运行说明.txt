=======================================================
   科级干部全周期管理与综合研判系统 - Windows 部署说明
=======================================================

【步骤一：拷贝项目到 Windows 电脑】
将整个「干部管理系统_项目开发」文件夹通过 U盘、网盘或局域网复制到 Windows 电脑任意目录
（建议放在 D:\干部管理系统 或桌面，路径中尽量不要有特殊符号）。

【步骤二：安装 Python（若电脑已安装可跳过）】
1. 从 Python 官网 (https://www.python.org/downloads/) 下载 Python 3.10 ~ 3.12 安装包。
2. 双击安装时，务必在第一步底部勾选：
   ☑ "Add python.exe to PATH"（添加到环境变量）
3. 按照提示点击 "Install Now" 完成安装。

【步骤三：一键安装系统依赖】
双击运行项目根目录下的：
   【一键安装依赖.bat】
脚本会自动调用国内清华镜像源高速下载安装 PySide6、openpyxl、python-docx、pypdf 等依赖。

【步骤四：启动运行系统（三种方式任选其一）】
安装完成后，平时启动系统推荐以下任意一种方式：
1. 双击运行【启动系统.bat】（或极简纯英启动脚本【run.bat】）；
2. 或者直接双击运行主入口【main.py】；
3. 或者打开 CMD/终端运行：python main.py。
即可直接打开系统界面！

【后续更新：一键同步最新修复】
平时如果云端有新功能或修复发布：
1. 方式一（单文件替换，最稳妥推荐）：若只是常规功能修复，您只需将最新修改的 cadre_core.py 复制替换覆盖 Windows 电脑上的同名文件即可，无需重装任何环境；
2. 方式二（Git 同步）：如果您的项目配置了 Git，双击【一键更新.bat】或运行 git pull 即可自动拉取云端最新代码。

【进阶可选：打包成独立免安装版 (.exe)】
如果想把软件分发给没有 Python 环境的领导或同事电脑：
双击运行根目录下的【打包为独立EXE(可选).bat】，完成后会在 dist 目录下生成完整的独立绿色程序包。
